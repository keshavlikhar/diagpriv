# Licensing scope

DiagPriv uses separate licensing scopes for software and research-publication
material.

## Software code

The software implementation is licensed under the Apache License, Version 2.0
(`Apache-2.0`) in the root `LICENSE` file. This includes the executable
Python source and supporting software/test infrastructure under directories
such as:

- `diagpriv/`
- `diagbench/` software modules
- `tests/`
- `.github/scripts/`
- executable experiment/reporting code

Unless a file states otherwise, contributions to those software portions are
made under Apache-2.0.

## Manuscript and research narrative

The paper manuscript, figures, prose documentation, and research narrative are
not automatically licensed under Apache-2.0 merely because they live in the
same repository. The authors will select the applicable preprint/publication
license separately when the manuscript is distributed through a preprint host
or venue.

## Data and provider observations

Provider-result JSONLs are not distributed by this repository and are not
covered by a public artifact license here.

Tracked synthetic fixtures, aggregate research data, and derived analysis
artifacts should not be assumed to carry Apache-2.0 rights unless their file or
directory explicitly says so. A separate data/benchmark license can be added
later if broader reuse is desired.

## No change to research claims

Licensing does not imply that DiagPriv provides anonymity, compliance,
production privacy guarantees, or provider-observation reproducibility.
